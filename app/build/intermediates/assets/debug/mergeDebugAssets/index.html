How the adaptive estimate works

This starter version estimates maintenance calories from a standard equation, then can refine the estimate using your logged intake and weight trend. It needs several weeks of reasonably consistent data; early estimates can be noisy. It does not connect to a cloud account, so your data stays in this browser on this phone.
